# Volim Mail updates

Official compiled app downloads and signed update metadata for Volim Mail.
This repository contains no application source code.

Download builds from [Releases](https://github.com/joe-2020/volim-mail-updates/releases).
The signed update feed is [latest.json](https://joe-2020.github.io/volim-mail-updates/updates/latest.json).

Build 123 is a mirror of the existing early-access release. New production releases require Developer ID signing and Apple notarization.
